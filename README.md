# DevOps Infrastructure Repository

## Project Overview
This repository manages cloud infrastructure, container deployments, and CI/CD pipelines.

## Directory Structure
- `infrastructure/terraform`: Infrastructure as Code (IaC)
- `infrastructure/ansible`: Configuration Management
- `infrastructure/kubernetes`: K8s manifests
- `infrastructure/docker`: Container specifications
- `infrastructure/monitoring`: Prometheus metrics
- `.github/workflows`: Automated CI/CD pipelines
